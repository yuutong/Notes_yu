# Notes_yu

个人 Markdown 笔记库，使用 Docsify 生成浏览站点。

- 站点入口：`index.html`
- 首页内容：`home.md`
- 笔记目录：`docs/`
- 格式检查：`node tools/format-markdown.mjs --check`
- 自动格式化：`node tools/format-markdown.mjs`
- 内容审计：`node tools/audit-markdown.mjs`
- 补齐标题：`npm run notes:titles`
- 合并重复笔记：`npm run notes:dedupe`
- 构建知识库：`npm run kb:build`
- 启动知识库聊天：`npm run kb:chat`
- 完整检查：`npm run check`
