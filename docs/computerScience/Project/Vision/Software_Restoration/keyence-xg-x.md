# Keyence XG-X VisionEditor 3.4：从还原计划到阶段成果

> 整理日期：2026-10-29。依据项目中的计划、源码、验证报告和会话归档整理；本文未重新执行测试。各数字为对应报告中的阶段快照，不能推断为所有输入或整机功能均已验证。

## 背景与目标

项目从 XG-X VisionEditor 3.4 的原始程序出发，希望恢复可编译、可运行的编辑器与检测算法，最终实现完整功能。原始 `bin`、`sim` 保持不变，恢复代码和证据集中在 `Code`。目标分为托管编辑器、原生算法、两者集成以及产品级验证：某个函数通过对照，或界面能够打开，都不能单独证明完整产品等价。

## 计划与方法

工作先盘点程序集和原生模块，再按六类 3D 工具定位参数、调用链和数值例程，恢复独立 C++ 库；随后构建托管编辑器、比较原版界面与工程操作，最后考虑将恢复库接入执行路径。后续又将检测分类的另外 25 个工具列为独立计划，按共享结构从面积、灰度和彩色统计推进到边缘家族，再逐步覆盖更复杂的识别和搜索。

具体方法是用 ILSpy 导出托管代码，用 RTTI、虚表、DSP 命令、Ghidra 伪代码及 x86 汇编追踪原生路径；依据输入输出探针和汇编修正反编译结果。在独立库中实现明确的数据结构和 C ABI，利用 Unicorn 执行原始指令，与恢复实现比较状态、输出、输入副作用及必要的逐字节结果。再用合成图像和较完整的工具流程验证组合行为，并保留脚本与 JSON 报告。浮点、调用约定、内存布局与算法公式一样需要核对。

## 六类 3D 工具的恢复

高度检测、轮廓检测、连续轮廓检测、3D 几何测量、3D 斑点和 3D 辨别形成独立恢复库，提供 JSON 命令行入口。报告记录 32 个文档化 API、37,112 例例程用例，六类工具通过合成产品级验收；覆盖高度统计和物理量转换、轮廓区域与采样、连续轮廓调度与拟合、28 个几何操作、斑点连通域与特征处理，以及辨别差异和平面拟合等。这里的“产品级”指报告中定义的合成场景，不代表真实设备与全部参数组合都已等价。

连续轮廓支撑平面的破解体现了迭代过程：早期归档记录 158/240 位等；通过结合汇编、旋转几何及探针，识别出被误判的叉积、Rodrigues 旋转和候选选择规则。后续项目 README 记录该专项达到 240/240 位等。不同归档的数字对应不同时间，不能混为同一次测试。

恢复库同时构建 x64 与 x86 版本。x86 DLL 已由真实 32 位进程加载并冒烟调用代表性 API；导出数量随后续扩展变化，应以 `validation/native-x86-build.json` 和实际构建报告为准。32 位全量例程测试及编辑器内封送仍需进一步验证。

## 编辑器源码与运行验证

47 个 ILSpy 项目中，46 个纯托管项目可通过解决方案从源码构建，依赖改为项目引用；`Vapi.Net` 是 C++/CLI 混合程序集，暂时保留原版 DLL。过程中修复了反编译产生的调用、类型转换和命名空间问题，补回被丢弃的空资源与中文卫星资源，并对齐 32 位程序的 Large Address Aware 标志，解决启动时的地址空间不足问题。

全源码入口已能启动中文主窗体。项目报告通过 UI Automation 对照了菜单展开、Tab 选择、选项对话框、工具箱分类，以及六类工具属性页的打开、枚举和关闭。隔离工作区中还比较了新建、关闭、重开、另存和再次重开的流程。属性页仍有 UIA provider 暴露差异，不能据此声称完整视觉树一致；KVI 容器的原始字节在重复创建时也可能不同，逻辑内容尚待解码比较。

## 扩展到其他检测工具

2026-09-30 起，计划把非 3D 的 25 个检测工具纳入同一证据流程，建立 UI 名称、托管类型、原生类、虚表、准备函数、DSP 命令与分派入口的对应关系。面积、浓淡和彩色检测已恢复部分行级统计内核；边缘家族逐步覆盖参数、采样调度、候选点、静态表、响应变换、结果转换、显示及内存和取行等层次，并用原始指令进行专项对照。

这些成果主要是共享内核和局部链路，不能等同于 25 个完整工具已恢复。完整回调、真实执行环境中的资源管理和全工具组合仍需按照最新覆盖矩阵逐项核实。

## 尚未完成与下一步

最重要的缺口是恢复库与编辑器执行链的闭环。已定位单单元执行经 `VASIMMeasurement.ExecuteUnitByInputImage` 进入 `Vapi.Net` 和原生引擎；高度检测可作为首个试点。合理顺序是在原版执行旁增加 shadow 模式，采集相同图像、区域、参数及结果，比较恢复库输出，确认坐标、stride、有效像素和封送后再考虑替换。显示层取图接口是否与引擎实际输入一致仍需验证。

同时应补充 32 位全量测试、KVI 逻辑负载对照、属性页参数与结果矩阵、其余检测工具完整调用链，以及真实设备和端到端工作流验证。每次保留环境、输入、原版与恢复结果及报告，明确区分位级一致、近似一致和仅通过合成场景。
